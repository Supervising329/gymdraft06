## Deploy through GitHub to Vercel

1. Upload every file and the `assets` folder to the GitHub repository root.
2. Import the repository into Vercel.
3. Select the **Other** framework preset and leave build settings empty.
4. Deploy from the repository root.
5. Enable Web Analytics and Speed Insights in the Vercel project dashboard.
